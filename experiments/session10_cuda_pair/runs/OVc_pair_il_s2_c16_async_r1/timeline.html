Timeline

Each rank has a compute row and a communication row. The compute row is device time, closed by a device sync. The communication row shows sends, waits and copies between the device and the host. The row "in flight" shows every frame from the start of its send to the end of the receiver's wait for it: the upper half is a frame this rank sent, the lower half one addressed to it. A color is the other rank. All times are on the coordinator clock.

Bytes per link

Bytes on the wire, frame headers included, counted by the sender. Decode steps only, then the whole run with prefill.

Clock alignment

Each rank's clock minus the coordinator's clock, from 16 round trips on the control link at the start and at the end of the run. The error is at most half the round trip. The table shows the wall clocks. Events are aligned with the same measurement of the monotonic clocks. The last column compares with the NTP measurement of the two hosts before the run.
